Status Langganan CLI Host

Plure memakai sesi CLI resmi milik Anda sendiri tanpa menjual ulang token dan tanpa meminta API key di browser.

Buka Plure dari HP Anda

Buat kode pairing sekali pakai (berlaku 15 menit). Untuk akses dari luar jaringan rumah, aktifkan Tailscale pada PC dan HP atau jalankan server dengan argumen --lan di Wi-Fi yang sama.
